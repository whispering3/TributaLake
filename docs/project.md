# TributaLake

## Identidade do projeto

- Nome do produto: TributaLake.
- Nome de distribuição pretendido: `tributa-lake`.
- Comando público: `tributa`.
- Responsável: Danilo Souza.
- Licença: MIT.
- Repositório: https://github.com/whispering3/TributaLake

## Escopo inicial aprovado

O primeiro módulo será EFD-Contribuições. A implementação dos leiautes será
liberada após o registro de fonte oficial, vigência, hash do material e aprovação
do contador indicado pela empresa usuária.

## Registro de disponibilidade

Em 29 de outubro de 2026, a URL pública do PyPI para `tributa-lake` retornou
ausência de projeto. Antes do primeiro release, repetir a verificação e publicar
o pacote a partir da organização GitHub definida por Danilo Souza.
